# アセットと表現の方針

登山・壁蹴り・空中ダッシュという一般的な体験を出発点に、地形・キャラクター・配色・台詞を独自に作る。
既存ゲームの名前・人物・ステージ名・会社名を製品の名前、README の売り文句、コード、コメント、台詞へ持ち込まない。
これは兄弟から採用した製品方針であり、商標法についての法的判断ではない。

既存ゲームのスクリーンショット、スプライト、マップ、音楽、台詞を複製・トレースしない。
手順と判定は取り込む。仕組みの字形、アスキーアート、絵文字は足さない。画面の枠と奥行きは [ADR 0024](adr/0024-depth-and-gleam.md)。判断は [ADR 0019](adr/0019-logic-not-pictures.md)。
初期はコードによる独自のセル描画、無音。生成アセットを採用する場合も出自・利用条件・加工を記録する。

兄弟の MIT コードを移植する場合は元リポジトリ・commit・対象ファイル・変更内容を
[REFERENCES](REFERENCES.md) に記録し、必要な著作権表示とライセンスを保持する。
第三者の素材を導入する場合はライセンスと再配布条件を確認し、出典一覧を追加する。
現在、第三者ゲームのアセットと移植した製品コードはない。
