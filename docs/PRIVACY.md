# プライバシー・保存の方針

製品の初期方針はオフライン動作。アカウント、解析、広告、テレメトリ、外部 AI API を導入しない。
通信はしない。

調査用の入力記録は、デバッグ定数が真のときだけローカルファイルへ書く。判断は [ADR 0013](adr/0013-trace-debug.md)。
形式は一行が空白区切りのテキスト。場所と権限は `PlayTrace` が持つ。いまの定数は偽で、ファイルは作らない。
真にしたときは起動ごとに作り直す。開けないとき、書けなくなったあとは、記録なしで遊びを続ける。ゲームは止めない。
消すときはそのファイルを消す。公開リポジトリへは入れない。

将来、登山記録や設定を保存するなら、必要なものだけをユーザー領域に置く。
保存形式・場所・読み書き失敗時の挙動・削除方法を実装と同じ変更で明記する。
保存失敗でゲームを止めるかメモリのみで続けるかは結果型として扱い、黙って破損を上書きしない。

開発用の依存取得・GitHub CI は製品の実行時通信とは区別する。
認証情報、ホームディレクトリの内容、会話ログ、個人情報を公開リポジトリへ含めない。
