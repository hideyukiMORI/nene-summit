  `make check` は文書、GIT-003、conformance、整形、lint、debug / release build、Swift Testing、
  PTY での起動と `q` を実行する。
- 文書検査が Swift ソースを拒む制限は外し、同じ `make check` の製品ゲートへ置き換えた。
- P1 の一部屋。判断は [ADR 0004](../adr/0004-one-room-step.md)。
  `RoomId` と `Room` が不正な部屋を拒み、`SummitState.advance` が tick を 1 進める。
  同じ入力列は `Replay.states` で同じ状態列になる。
- 人が一部屋を遊ぶ。判断は [ADR 0005](../adr/0005-playable-climb.md)。
  走る、跳ぶ、壁蹴り、ダッシュ、棘、チェックポイント、登頂、`q` で終了。
  数は `MotionPolicy` の設計判断であり、施主の確定要件ではない。
  起動は `swift run nene-summit`。矢印か a d、w と s、space、k、q。
- 無入力の案内。判断は [ADR 0006](../adr/0006-unattended-retry.md)。
  キーが無い tick は右へ跳ぶ案内が `advance` だけを呼ぶ。
  頂上のあと、または打ち切りで、同じ部屋を最初からやり直す。
  人の入力がある tick は人が勝つ。間と打ち切りは `Watch` の設計判断。
- 短いジャンプと、一部屋の読み、画面下の案内。判断は [ADR 0007](../adr/0007-shorter-jump.md)。
  全力のジャンプは体のおよそ 3 倍。数は `MotionPolicy`。参照作品の地形は写していない。
  部屋は、チェックポイント、棘、ジャンプでは越せない隙間、短い階段、頂上の順。
  画面の下に題、ダッシュの印、キーの一行。
- 押しっぱなしと同時押し。判断は [ADR 0008](../adr/0008-held-keys.md)。
  離すまで移動が残り、1 回の読みの複数キーは一つの `Input`。
  ジャンプとダッシュは押し始めだけ。ジャンプを離すと、上がっている速度を一度短くする。
  窓の長さは `HeldPresses`、短縮は `MotionPolicy`。施主の実測ではない。
- オートとマニュアルの切替。判断は [ADR 0009](../adr/0009-attendance-toggle.md)。
  起動はオート。`m` の押し始めだけで切り替える。マニュアルでは、キーが無くても案内を呼ばない。
  モードは `Input` に入れない。
- ジャンプ中の左右。判断は [ADR 0010](../adr/0010-jump-steer.md)。
  方向を押したまま跳ぶと、その走る速さで出る。空中の左右も、その tick で走る速さへ届く。
  ジャンプキーはスペースのまま。シフトにはしない。
  実機の記録では、右を押しても軌道はほぼ真上で、浮島への移動になっていなかった。
- 方向を押したジャンプの斜め。判断は [ADR 0012](../adr/0012-up-right-jump.md)。
  方向を押しているあいだ、上への速さと揃った横速度を保つ。地面の走りは走る速さのまま。
  右を押した全力のジャンプを二回続けると、下の浮島に着く。頂上のやり直しは変えていない。
- 実機の入力記録。判断は [ADR 0013](../adr/0013-trace-debug.md)。
  `PlayTrace.debug` が真のときだけローカルファイルへ書く。いまは偽。行の形は [ADR 0011](../adr/0011-input-trace.md)。
- 頂上のあと次の部屋。判断は [ADR 0014](../adr/0014-next-room.md)。
  道は二部屋。頂上の続きは次の部屋から `advance` する。最後のあと最初へ戻る。
  登頂できないときの打ち切りは、同じ部屋のまま。案内の跳び方は足していない。
- 画面の下のボヤキと、枠の外を消すこと。判断は [ADR 0015](../adr/0015-mutter-strip.md)。
  行の残りと枠の下は消す。帯の位置と一人の日本語は 0016 が置き換えた。
- 固定の色面と英語の四人。判断は [ADR 0016](../adr/0016-color-screen.md)。
  画面の大きさは部屋で変えない。山は背景色。文字は題、右の状態、ボヤキ、キー。
  部屋が窓より広ければ、窓の中だけ体を追う。声は四人が順に話す。
  行はカーソル位置で書き、改行では送らない。一フレームは末尾まで書く。
- 案内の先読み。判断は [ADR 0017](../adr/0017-lookahead.md)。
  候補は複製した状態へ `advance` して比べる。本番の状態は選んだ入力で一度だけ進む。
- ばねと動く床。判断は [ADR 0018](../adr/0018-spring-and-deck.md)。
  ばねは上へ弾いてダッシュを戻す。床は横と上へ動き、立っていれば体を運ぶ。
  道は二部屋のあと、ばね、横の床、上の床、そして最初へ戻る。
- 絵は足さず、仕組みのロジックだけ取り込む。判断は [ADR 0019](../adr/0019-logic-not-pictures.md)。
  仕組みの字形、アスキーアート、絵文字は足さない。画面の枠は 0024。
- 壁に沿って上る井戸。判断は [ADR 0020](../adr/0020-wall-well.md)。
  上へ運ぶ床のあと、細い縦穴を壁に沿って登る。字形は足していない。そのあとの隙間は 0022。
- 画面の刻みは枠の残りだけ待つ。判断は [ADR 0021](../adr/0021-steady-pace.md)。
  1 tick に描画は 1 回。遅れは、描かない tick で取り戻さない。物理の速度は変えていない。
  実機ではいい感じだったので、枠は少し短くした。数は `FramePace`。
- 低い隙間。判断は [ADR 0022](../adr/0022-low-slot.md)。
  井戸のあと、天井が低く棘で切れた横穴をダッシュで越え、最初の部屋へ戻る。字形は足していない。
- 色面と右の欄。判断は [ADR 0023](../adr/0023-color-and-hud.md)。
  空は暗い青、岩は暖色、文字は暗い地。右は状態の項目と、名前と顔と文に分かれた通信。
  得点、残機、配色の切替は足していない。画面の枠は 0024。
- 画面の枠と奥行きと、拾う光。判断は [ADR 0024](../adr/0024-depth-and-gleam.md)。
  上下の帯は盤面と地が違う。窓と右の欄に幅 1 の枠。奥の山は描画だけが遅らせる。
  光は `advance` だけが拾い、落ちても残る。右の欄に数を出す。残機でも得点でもない。
  実機の色と、枠が幅 1 で出るかは未計測。
