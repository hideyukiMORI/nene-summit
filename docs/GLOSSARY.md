# 用語

| 用語 | 意味 |
| --- | --- |
| climber | 登山するキャラクター |
| room | チェックポイントと出口を持つ地形の単位 |
| expedition | 開始から登頂または終了までの一回の登山 |
| tick | ゲーム状態を進める固定単位。秒への対応は合成ルートが持つ |
| step | 状態と入力を受け取る Core の一刻みの処理 |
| dash | 空中を短時間高速移動する入力・状態 |
| checkpoint | 失敗時に復帰する検証済みの地点 |
| composition root / 合成ルート | executable。時計・seed・端末・各モジュールを組み立てる唯一の場所 |
| seed | 再生を再現するための乱数の初期値 |
| gate | 変更の合否を判定する実行可能な検査 |
| negative proof | 意図した違反が意図した検査で拒否される証拠 |
| ADR | 長期的な設計判断と理由の記録 |
| waiver | 範囲と期限を限定した規約の例外 |
