# ADR 0040 — 落ちた次は上から落ち続ける

Status: accepted
Date: 2026-11-03
Issue: #83
Scope: 下へ出た次は、落ちた列の上から空中に入り、下向きの速度のまま落ち続ける。穴の次の部屋は窓の上まで空ける。

## 背景

0039 の画面を施主が見た。2 画面目か 3 画面目で、左から出たように見えて左から出た、と言った。
穴に落ちた移動だった。
落ちた次は、上から出て、そのまま落ち続けないとおかしい、と言った。
0038 の「下へ出たら上から入る」は、入りのマスを部屋の印の列に置いていた。穴の次は左の床だった。

## 判断

下へ出た次は、落ちた列に近い、上から床まで空いている列の、いちばん上の空きに置く。
その列の着地が棘なら、隣の空いている列を使う。棘の上には落とさない。
入りは空中にする。下向きの速度があれば残す。無ければ、その場から落ち始める。
着地した状態にはしない。
穴の次の部屋は、窓の上まで空いている。落ちは画面の上から床まで続く。
最初の縦穴は伸ばさない。窓の上まで伸ばすと、出る場所が上へ移り、案内が抜けられなかった。
戻りでその縦穴へ落ちるときは、その穴の上から空中で落ちる。画面の上までは届かない。
新しい物理は足さない。空中の二度目は 0037 の一度のまま。三度目は足さない。
参照のタイルと名前は写さない。

## 比較した案

落ちた列が棘でも、そのまま落とす案は採らない。入った瞬間に死ぬ。
最初の縦穴も窓の上まで伸ばす案は採らない。案内が上へ抜けられなかった。
下へ出た次を、床に立たせてから歩き始める案は採らない。施主が、落ち続けないとおかしい、と言った。

## 影響と検証

0038 の「下へ出たら上から」は残る。着地の位置と、落ち続けることをこの判断が足す。
0039 の道と旗は残る。穴の次の部屋だけ、上の空きを足す。
実機の感触は未計測。施主はこの画面をまだ見ていない。
