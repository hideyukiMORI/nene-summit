# ADR 0041 — 山はカメラとずれ、頂上は右上に開く

Status: accepted
Date: 2026-11-03
Issue: #85
Scope: 窓より広い部屋では奥の山がカメラより遅くずれ、旗は下から登った右上の空きにある。運ぶ床は、壁の相で横に接して上る。

## 背景

0040 の画面を施主が見た。落ちるところは良くなっている、と言った。
山は相変わらず上に固定だ、と言った。
壁キックと、動く床へ壁のようについて上る仕掛けを、何度も足してほしい、と言った。
パララックスで画面が動く段、消える足場、落ちる橋が欲しい、と言った。
下から出てすぐ旗では、頂上に着いた感じがしない、と言った。
下から出て、頂上で開けた右上に旗がある、と言った。
参照の序盤の画面の仕掛けを、名前とタイルは写さず、順番のたたき台にする、と言った。

## 判断

奥の雲と稜線は、部屋の中の空にも描く。
0027 の「部屋の中の空に山を描かない」は、この奥の層だけ置き換える。
手前の雪は、奥が描かない空きに残る。
雲は稜線より遅く、稜線はカメラより遅くずれる。横も縦も同じ。
窓に収まる部屋は、0030 のままカメラを動かさない。その画面では山も動かない。

最初の部屋と旗の部屋は、窓より広く、窓より高い。
旗の部屋は下から入る。入りの床は消える足場で、その下は空いている。
旗は右上の空きに一本。入りの真上には置かない。
運ぶ縦の床の部屋も窓より高い。
階段の先に縦の床があり、その下は棘。
案内は壁の相でその床の横につき、上へ運ばれてから右の高い口を出る。
地面にいて出口が上なら、案内は真上へのジャンプを一度試す。
横へ跳ぶと、上の狭い口から外へずれる。
これは同じジャンプで、空中の三度目ではない。部屋ごとの跳び方ではない。

道の順は、登る、壁、落ちる、消える足場と落ちる塊、もう一つの壁、縦穴、運ぶ床、ダッシュ、横の床、尖塔、開いた頂上。
参照のタイルと名前は写していない。
新しい物理は足していない。速度は動かしていない。
空中の二度目は 0037 の一度のまま。

## 比較した案

窓に収まる部屋でも、刻みで山を流す案は採らない。施主が欲しいのは、画面が動く段である。
十部屋を全部、窓より高くする案は採らない。最初と、運ぶ床と、旗の部屋を動かす。
真上の縦穴だけを伸ばす案は採らない。案内が抜けられなかった。
旗を入りの真上に置く案は採らない。施主が、すぐ旗では着いた感じがしない、と言った。

## 影響と検証

0040 の落ち方は残る。穴の次は上から空中で落ち続ける。
0039 の折れは残る。旗の部屋の形と、最初の部屋の高さと、運ぶ床の部屋の高さをこの判断が置き換える。
0030 は残る。窓に収まる部屋のカメラは動かさない。
実機の感触は未計測。施主はこの画面をまだ見ていない。
