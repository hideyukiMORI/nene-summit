# ADR 0027 — 頂は一本の旗、奥の雲は輪郭

Status: accepted
Date: 2026-11-01
Issue: #53
Scope: 施主が、頂に旗が何本も立つのを違うと言い、唇の上の旗一本をスケッチした。奥の雲と稜線は、二つの見方を突き合わせて直す。

## 背景

頂上のマスが、どれも同じペナントだった。
奥の雲と雪の地平が同じ字で、稜線の東側が雪の手前で途切れていた。遠い頂は棘と同じ字だった。

## 判断

横に続く頂上は一つの唇にする。旗は列の中央に一本。左から数えて、個数の半分の位置。当たりは頂上のまま。
チェックポイントの杭は変えない。
雲は輪郭。腹だけ一段暗い。稜線は左右とも太い斜線で、頂は雪の字。東の裾を一マス足して雪の線まで下ろす。
雪の地平は穴を残す。部屋の中の空には山を描かない。山の中身は塗らない。
色番号は `Painter` に置く。

## 比較した案

唇を床の線にする案は採らない。施主のスケッチは中段の横線だった。
近い丘を部屋の空へ出す案は採らない。跳ぶ場所と重なる。
山の中身を塗る案は採らない。輪郭で足りる。

## 影響と検証

物理と部屋の形は動かさない。実機の色と、罫の幅は未計測。
