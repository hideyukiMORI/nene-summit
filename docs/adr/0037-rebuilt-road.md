# ADR 0037 — 道を最初から組み直す

Status: accepted
Date: 2026-11-03
Issue: #77
Scope: 遊び始めの道を、上、壁、つかまり、左、下、井戸、ダッシュで折る。空中でもう一度だけ跳べる。画面は帯で組む。

## 背景

0036 は、崩れる橋のあとに五部屋を足した。
施主はその画面を見て、一回しか上へ行っていない、と言った。
壁キック、壁に張り付いたまま運ばれる塊、空中の二度目は、道の上で何度も要る、とも言った。
0036 は空中の二度目を、いまあるダッシュだけにしていた。
画面は、選んだ帯に合わせる。上に題とモード、右に道順と体勢と声、下に反転したキー。

## 判断

道の最初は、上へ抜ける部屋にする。旗の部屋のあとは、その最初へ戻る。
続く部屋は、壁を蹴る尾根、横から運ぶ昇る床、左の端、下の穴、もう一つの井戸、棘をダッシュで越す部屋。
柱の高さは、尾根と井戸と頂上で揃えない。
空中では、着地するまでもう一度だけ跳べる。着地と、ダッシュの補充と同じタイミングで戻る。
回数は `MotionPolicy` の設計判断であり、施主の確定した数ではない。三度目は足さない。
ダッシュと壁キックは残す。案内は、新しい道で上の出口が遠いときだけ、空中の二度目を使う。
以前の部屋では、案内は空中でジャンプを押さない。
縦に動く床は、横に接した体も運ぶ。落ちる塊は運ばない。
案内は戻る向きを選ばない。最初の部屋は、人が戻って古い橋へ出ない。
画面の右は、道順、体勢、声の三つに分ける。高さの数は出さない。得点も残機も配色の切替も足さない。
参照のタイルと名前は写さない。

## 比較した案

0036 の五部屋を橋のあとに残す案は採らない。遊び始めが右の廊下のままになる。
空中の二度目をダッシュのままにする案は採らない。施主が、別のジャンプとして要ると言った。
空中で何度でも跳べる案は採らない。着地するまで一度にする。
案内に、部屋ごとの跳び方を書く案は採らない。先読みの候補に、新しい道の空中だけ二度目を足す。

## 影響と検証

0036 の「橋のあと五部屋」と「空中の二度目はダッシュだけ」はこの判断が置き換える。
0036 の端の向き、横から運ぶ縦の床、案内が戻らないことは残る。
案内は最初の部屋から旗まで渡り、壁を二度蹴り、空中でもう一度跳び、果実か硬貨を持って着く。
実機の感触は未計測。施主はこの画面をまだ見ていない。
