# ADR 0025 — 山は罫で描き、拾うものに字形を付ける

Status: accepted
Date: 2026-11-01
Issue: #49
Scope: 施主が、面だけの正方形をやめ、基本は罫、要るところはアスキー、拾えるものは工夫する、と求めた。

## 背景

山も人も棘も、同じ正方形の面だった。
施主は、基本は罫で描き、装飾が要るところにはアスキーを入れ、果実や硬貨のように拾えるものを工夫することを求めた。
[ADR 0019](0019-logic-not-pictures.md) は参照作品の絵をトレースしない。山の面を字形にしない、とは施主は言っていない。

## 判断

床と岩は罫。人、棘、ばね、旗、頂、果実、硬貨は幅 2 の短い字形。
空と帯は塗りのまま。きらめきは小さな弱い光のまま。
果実と硬貨は `SummitState.advance` だけが拾い、落ちても数は残る。残機でも得点でもない。
作品の果実の名前、人物、ステージ名は入れない。色番号は `Painter` に置く。

## 比較した案

面のまま色だけ変える案は採らない。施主は正方形を基本にしないと定めた。
拾うものを残機や得点にする案は採らない。数は持っているものだけ。

## 影響と検証

[ADR 0019](0019-logic-not-pictures.md) の「新しい字形を足さない」は、参照作品の絵をトレースしないことに残す。山の罫と拾うものは本決定。
枠の幅と、罫が端末で幅 1 に出るかは未計測。
雪山の雲と稜線、雪の床は [ADR 0026](0026-ice-vista.md)。
