# ADR 0032 — 崩れる床は二つの岸のあいだの橋

Status: accepted
Date: 2026-11-02
Issue: #67
Scope: 公開の全体図に、二つの岸を崩れる床で渡る橋がある。名前と外形は写さない。

## 背景

崩れる床は、頭上の蓋と、床に接した棘の廊下だった。
渡りに見えず、案内は蓋の下を歩くだけだった。
消える周期は tick だけで、踏んだ記憶では消さない。これは [ADR 0028](0028-falling-traps.md) のまま。

## 判断

崩れる床は、二つの岸のあいだに渡す。直下は空き、棘はその底に置く。
頭上の蓋は外す。部屋は窓に収める。
案内は渡りに乗って登頂する。跳び方は部屋ごとに足さない。
速度と周期は動かさない。参照の橋は写さない。

## 比較した案

踏んだ記録で一マスずつ消す案は採らない。0028 で見送っている。
棘を渡りに接したままにする案は採らない。廊下に見える。
渡りを窓より広くする案は採らない。両岸が一度に見えない。

## 影響と検証

Swift Testing が、崩れる床の直下が空きであること、案内が渡りに乗って登頂することを見る。
題は BRIDGE。道の順は変えない。実機の感触は未計測。
