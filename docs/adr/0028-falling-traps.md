# ADR 0028 — 落ちる塊と崩れる床と結晶

Status: accepted
Date: 2026-11-01
Issue: #55
Scope: 施主が、部屋と仕掛けが足りない、落ちてくるものや罠を公開の資料で調べて足すよう求めた。

## 背景

道は七部屋だった。ばね、動く床、棘、光、硬貨はある。
落ちてくる塊、しばらくで消える床、ダッシュを戻す結晶は無かった。
公開の一覧には、落ちる足場、崩れる床、触れるとダッシュが戻る結晶がある。名前と部屋の形は写さない。

## 判断

塊は `D`。位置は tick だけ。下へ落ち、底で待って、戻る。運ばない。重なれば棘と同じく倒れる。
崩れる床は `f`。しばらく固く、それから空き、また戻る。周期は tick だけ。
結晶は `R`。重なるとダッシュを満タンに戻す。固くはない。
速さ、落ちる距離、周期は `MotionPolicy` に置く。この文書へ写さない。
道は、低い隙間のあと、塊の部屋、崩れる床の部屋、そして最初へ戻る。
登頂は、落ちてくる塊の列を越え、崩れる床の上を通る。脇に置くだけでは、落ちてくる感じにならない。
案内の跳び方は部屋ごとに足さない。当たりは `SummitState.advance` だけ。

## 比較した案

塊を毎 tick 地図へ焼き込む案は採らない。先読みが戻し忘れる。
崩れる床を、踏んだ記憶で消す案は今回は採らない。周期だけで足りる。
参照作品の部屋をなぞる案は採らない。

## 影響と検証

[ADR 0018](0018-spring-and-deck.md) の動く床は残る。塊は運ばない。
Swift Testing が、塊の下で倒れること、崩れる床が消えて戻ること、結晶がダッシュを戻すこと、
無入力で新しい部屋を登頂することを見る。
実機の感触は未計測。
