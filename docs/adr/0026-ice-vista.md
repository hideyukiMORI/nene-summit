# ADR 0026 — 奥は雲と稜線、手前は雪

Status: accepted
Date: 2026-11-01
Issue: #51
Scope: 施主が、字形をもう少しかっこよく、奥を山や雲の風景に、世界を雪山の氷として描くことを求めた。

## 背景

[ADR 0025](0025-line-marks.md) の字形は、名前の札に見えた。奥は縦線の縞で、山にも雲にも見えなかった。
施主は氷の雪山をイメージしている。

## 判断

字形は輪郭で読ませる。人は頭と手足、棘は氷柱、旗は標識、頂はペナント、果実と硬貨は丸い印。
床の上面は雪、埋まった面は氷の縦罫。空の地は黒のまま。
奥は描画だけ。雲は稜線より遅く、稜線はカメラより遅く滑る。当たりは変えない。
きらめきは小さな弱い光のまま。色番号は `Painter` に置く。作品の名前は入れない。

## 比較した案

縦線の縞を濃くする案は採らない。風景の輪郭にならない。
雪を面の正方形に戻す案は採らない。施主は面を基本にしていない。

## 影響と検証

物理の速度は動かさない。罫が端末で幅 1 に出るか、実機の色は未計測。
頂の旗一本と、雲の輪郭は [ADR 0027](0027-one-pennant.md)。
雲の欠けと、大きな塊は [ADR 0029](0029-flat-cloud-wide-fall.md)。
落ちる塊と崩れる床と結晶は [ADR 0028](0028-falling-traps.md)。
