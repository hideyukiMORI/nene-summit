# ADR 0019 — 絵は足さず、仕組みのロジックだけ取り込む

Status: accepted
Date: 2026-11-01
Issue: #35
Scope: 施主の方針。参照する遊びの名前と絵は製品に入れない、という既存の表現方針の上に置く。

## 背景

画面は色面である。山は背景色、文字は題と状態とボヤキとキーだけ。
参照する遊びには、絵、図形、アスキーでは表せない見た目がある。
施主は、その絵は作らなくてよい、ロジックは取り込む、と定めた。

## 判断

新しい仕組みは、判定と手順として `SummitState.advance` に載せる。
見た目は、すでにある色面のトーンで足りる。ばねも床も、新しい字形を足さない。
アスキーアート、絵文字、参照作品の図は作らない。
部屋の並びと障害の意味はロジックとして取り、絵のトレースはしない。
作品の名前、人物、ステージ名は製品に入れない。

## 比較した案

仕組みごとに専用の文字絵を足す案は採らない。画面がアスキーの図鑑になる。
ロジックも見送る案は採らない。施主は手順を取り込むと定めた。

## 影響と検証

[アセット方針](../ASSET_POLICY.md) は、絵を複製しないことに加え、新しい字形を足さないことを本決定に委ねる。
この変更は文書だけ。描画と物理は動かしていない。
壁の井戸以降も、仕組みはロジックだけ足す。
画面の枠は施主が求めたので [ADR 0024](0024-depth-and-gleam.md)。「箱線は足さない」は施主の言葉ではなく、この決定を書いたときにこちらが広げた言い方だった。
