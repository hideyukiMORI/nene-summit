# ADR 0043 — 果実と硬貨は地の色で分け、尖塔は左から登る

Status: accepted
Date: 2026-11-03
Issue: #89
Scope: 果実と硬貨の字形と地の色を違える。渡し舟の次は左から入り、窓より大きい。その先に横長の部屋を一枚足す。

## 背景

0042 の画面を施主が見た。いい感じだ、と言った。
果実と硬貨の見分けが付かない。色を付け、他の背景とも分けてほしい、と言った。
まだやっていない段があるので、続けてほしい、と言った。

## 判断

果実は丸い字、硬貨は別の字。地の色は互いに違い、空の地とも違う。
色番号は `Painter` に置く。欄の見出しも同じ色にする。
当たりは変えない。拾うのは `advance` のまま。
尖塔は、左の空きに着く。階段を登ると上へ抜ける。部屋は窓より広い。
階段の上は、旗の部屋の前に横へ長い部屋を一枚足す。棘の列はダッシュで越える。
旗の部屋は下から入るまま。
参照のタイルと名前は写していない。
新しい物理は足していない。速度は動かしていない。
空中の二度目は 0037 の一度のまま。
窓に収まる部屋のカメラは 0030 のまま動かさない。

## 比較した案

字形だけ変えて地の色を空のままにする案は採らない。施主が、背景とも分けてほしい、と言った。
尖塔の着地を右に残す案は採らない。出た側の反対から入る。
横長の部屋を旗のあとに置く案は採らない。旗は道の最後のまま。

## 影響と検証

0042 の旗と雲と三段は残る。拾うものの見え方と、尖塔の入りと、一枚の横長をこの判断が足す。
渡し舟は、跳べば床に乗らずに越せる。窓に収まる部屋のカメラは動かない。
実機の感触は未計測。施主はこの画面をまだ見ていない。
