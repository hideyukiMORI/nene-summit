# ADR 0023 — 色面を整え、右の欄を段で組む

Status: accepted
Date: 2026-11-01
Issue: #43
Scope: 設計案。施主は、色と背景を整え、右の欄を参考作品の密度まで作り込むよう求めた。色番号は施主の指定ではない。

## 背景

山は背景色の面で、文字は題と右の状態とボヤキとキーだけ。
岩が明るすぎて空から飛び、見出しと印の色が奪い合っていた。
右の欄は項目が横に続き、通信は名前も文も同じ色だった。
ChatGPT の中にカードを出すデザイン一式は、この端末の画面には載らない。

## 判断

色は `Painter` の役割だけを整える。数はこの文書へ写さない。
空は暗い青、岩は白い塊より暗い暖色、棘と人と頂上とばねは役割が離れ続ける。
文字は暗い地の上に置く。山のマスは背景色のまま。
右の欄は、状態の項目をラベルと値に分け、その下に通信を置く。
通信は名前、顔、文を分ける。ダッシュは色面と短い語の両方で示す。
得点、残機、配色の切替、箱線、新しい字形は足さない。

## 比較した案

参照作品の枠線を写す案は採らない。箱線は足さないと既に決まっている。
得点と残機を足して密度を出す案は採らない。画面の方針が拒む。
ウェブ用の配色をそのまま塗る案は採らない。端末の 256 色と役割がずれる。

## 影響と検証

[ADR 0016](0016-color-screen.md) の「色の面」と「文字は題と状態とボヤキとキー」は残る。本決定は、その中の色と段を整える。
Swift Testing が、枠の大きさ、山に `#` と `^` が無いこと、状態の項目、通信の名前と顔と文、
マニュアルでは AUTO が無いこと、登頂で題が替わることを見る。
実機の色の感触は未計測。
