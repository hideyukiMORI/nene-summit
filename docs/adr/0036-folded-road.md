# ADR 0036 — 橋のあと、道を折る

Status: accepted
Date: 2026-11-03
Issue: #75
Scope: 崩れる橋のあと、右だけへ続く並びを、上、左、下、昇る塊、空中のダッシュに折る。

## 背景

0035 の橋のあとは、右の端を越えて次の画面へ出る部屋が続いていた。
歩く向きはほぼ右だけだった。
参照の本線は、上へ出て、左へ戻り、下へ抜け、動く塊に捕まって運ばれ、空中でもう一度進む。
同じつながりを、こちらのマスと部屋名で短く置く。参照のタイルと名前は写さない。
空中の二度目は、いまあるダッシュである。同じジャンプをもう一度足さない。

## 判断

橋のあと五部屋。出る端は、上、左、下、右、右。
上の部屋は左の壁に沿って天井を抜ける。左の部屋は果実と硬貨を拾って左の端へ出る。
下の部屋は床の穴から下へ抜ける。次の部屋は、横に接した昇る床が体を運び、上の棚から右へ出る。
最後の部屋は棘の隙間を、いまあるダッシュで越して右へ出る。旗は最後の部屋だけ。
縦に動く床は、立っている体に加え、横に接している体も運ぶ。落ちる塊は運ばない。
隣へ出る向きは部屋ごとに一つ。案内は戻る向きを失敗として扱い、選ばない。人は戻れる。
到着は、出た向きの反対の端に立つ。上か下から入った部屋は、その部屋の開始位置に立つ。
案内の跳び方を部屋ごとに書き分けない。物理の数は足さない。踏んだ記録では床を消さない。

## 比較した案

右だけの並びを残す案は採らない。端を越えても、向きが右のままになる。
参照のタイルと部屋名を写す案は採らない。つながりだけを、こちらのマスで置く。
同じジャンプをもう一度足す案は採らない。空中の二度目は、いまあるダッシュで足りる。
道を部屋の網に広げる案は採らない。順は Trail のまま、出る端だけを部屋が持つ。

## 影響と検証

0035 の「橋のあと、右へ続く部屋」はこの判断が置き換える。
0034 の端、0035 の井戸と崩れる橋、旗が最後だけであることは残る。
案内は上、左、下の端を越えて進み、昇る床に横から運ばれ、棘の隙間でダッシュを使う。
果実か硬貨を持って旗の部屋へ着く。実機の感触は未計測。
