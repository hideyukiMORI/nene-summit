# ADR 0030 — 窓に収まる部屋はカメラを止め、広い部屋は先を見せる

Status: accepted
Date: 2026-11-02
Issue: #63
Scope: 本編の画面をコマに切って見た。説明用の別キャラの場面は使っていない。

## 背景

画面いっぱいの部屋では、カメラが動かず、人がその中を横切っていた。
渡る弧の空中に結晶があり、下は棘だった。部屋が替わると、次の一枚に切り替わっていた。
窓より広い場所だけカメラが動き、人より先の足場が見えていた。端では人が端に寄る。
今の広い部屋は人を中央に置く。先の足場が半分隠れる。

## 判断

窓に収まる部屋は、カメラを動かさない。
窓より広い部屋は、人を中央に置かない。進行方向の足場を先に見せる。端では出口を切らない。
道に、窓に収まる一枚を足す。棘の上を渡る弧の空中に結晶を置く。
案内の跳び方は部屋ごとに足さない。参照の地形と名前は写さない。
[ADR 0029](0029-flat-cloud-wide-fall.md) の広い部屋は、窓より狭くしない。

## 比較した案

広い部屋を全部窓に収める案は採らない。先が見えるスクロールは残す。
カメラを滑らかに追う案は採らない。低解像度では人が震える。
結晶を床に戻す案は採らない。弧の空中に置く。

## 影響と検証

Swift Testing が、広い部屋で先が見えること、新しい一枚が窓に収まりカメラが動かないこと、
案内が結晶のマスを通って登頂することを見る。
実機の感触は未計測。
