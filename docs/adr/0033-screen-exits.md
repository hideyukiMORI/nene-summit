# ADR 0033 — 途中の部屋は画面の出口、旗は最後だけ

Status: accepted
Date: 2026-11-02
Issue: #69
Scope: 頂上に旗がある。それまでの部屋は、旗を目指すのではなく、出口から次の画面へ移る。

## 背景

各部屋の終わりは旗の列で、触れると登頂になり、題が CREST になってから次の部屋へ進んでいた。
道の最後だけが頂上で、それまでは画面を抜ける移動である。

## 判断

途中の部屋の終わりは出口にする。出口は `>>` で、旗の色にはしない。
出口に触れるとその場で次の画面へ移る。CREST にはしない。
旗は道の最後の部屋だけに残す。登頂の停止と CREST はその部屋だけ。
案内の跳び方は足さない。速度は動かさない。参照の部屋割りは写さない。

## 比較した案

出口も登頂として止め、題だけ変える案は採らない。画面の移動に見えない。
旗を全部外す案は採らない。頂上の旗は残す。
部屋ごとに旗を一本ずつ残す案は採らない。画面の目標が旗のままになる。

## 影響と検証

Swift Testing が、途中の部屋を抜けると次の画面で登り続け、最後の部屋だけ登頂することを見る。
旗は最後の部屋に一本。最初の部屋の同じ位置は出口。
道の順は変えない。実機の感触は未計測。
