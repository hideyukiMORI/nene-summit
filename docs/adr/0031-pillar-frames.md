# ADR 0031 — 部屋は高さの違う柱と、枠の一枚にする

Status: accepted
Date: 2026-11-02
Issue: #65
Scope: 序盤から本編をコマで追い直した。説明用の別キャラの場面は使っていない。

## 背景

序盤の足場は、高さの違う柱だった。頭は明るく、腹は暗い縦で、腹に欠けがある。
人は柱の間を渡り、次の柱が先に見えていた。
窓に収まる部屋は枠で囲まれ、問題が一枚に入っていた。
今の部屋は一本の床と空の点で、その輪郭がない。

## 判断

歩きの列、穴、頂、結晶の弧、落ちる塊の穴は動かさない。
その上と左右に、高さの違う柱を立てる。頭は雪、腹は縦の罫、腹に一マスの欠けを入れる。
窓に収まる部屋は左右を壁にし、上に欠けた天井を置く。
案内の跳び方は部屋ごとに足さない。カメラは [ADR 0030](0030-locked-screen-lead.md) のまま。
落ちる部屋は [ADR 0029](0029-flat-cloud-wide-fall.md) のとおり窓より狭くしない。
参照の地形と名前は写さない。速度は MotionPolicy のまま。

## 比較した案

床そのものを柱の上面へ組み直す案は採らない。案内は待たずに歩き、離れた穴へ落ちる。
部屋を窓の上まで固体で埋める案は採らない。跳ぶ弧が潰れる。
カメラを滑らかに追う案は採らない。0030 と同じ理由。

## 影響と検証

Swift Testing が、柱の高さが違うこと、腹の欠け、枠の左右の壁、案内の登頂を見る。
字形は足さない。実機の感触は未計測。
