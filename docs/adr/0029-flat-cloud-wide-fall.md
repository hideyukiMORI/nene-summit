# ADR 0029 — 雲は平たい欠け、落ちる塊は大きく、その部屋は窓より広い

Status: accepted
Date: 2026-11-02
Issue: #61
Scope: 施主が、雲が丸く月や太陽に見えると言い、落ちてくる塊がデモでほとんど見えないと言った。大きくし、地図が流れる感じにしてほしい、と求めた。

## 背景

奥の雲は輪郭だったが、上下が対称の皿だった。
落ちる塊は一マスだった。その部屋は窓より小さく、カメラは動かなかった。

## 判断

雲は輪郭のまま。上は短く、腹は長く、腹の途中を欠く。下は二股で、上の鏡にしない。
丸い括弧で皿にしない。部屋の中の空には山を描かない。
落ちる塊は、横に続く複数マスにする。一マスの印に戻さない。運ばない。位置は tick だけ。
その部屋は窓より広くする。登るあいだ、カメラは横へ動く。
速さは変えない。案内の跳び方は部屋ごとに足さない。

## 比較した案

雲を塗って円を消す案は採らない。輪郭で足りる。
塊を毎 tick 地図へ焼く案は採らない。先読みが戻し忘れる。
全部の部屋を窓より広くする案は、今回は採らない。見えないのは落ちる塊の部屋だった。

## 影響と検証

[ADR 0027](0027-one-pennant.md) の雲は輪郭のまま。形の対称は本決定が置き換える。
[ADR 0028](0028-falling-traps.md) の塊は残る。大きさだけ広がる。
Swift Testing が、雲のずれ、部屋が窓より広いこと、案内が塊の列を越えるあいだに塊が落ちること、登頂することを見る。
実機の感触は未計測。
