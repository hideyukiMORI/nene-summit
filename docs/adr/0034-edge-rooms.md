# ADR 0034 — 端を越えると隣の画面

Status: accepted
Date: 2026-11-02
Issue: #71
Scope: 途中の部屋は、中の印ではなく、端の開口で隣の画面へ続く。旗は最後だけ。

## 背景

0033 は途中の部屋の旗を `>>` に変えた。触れる場所は部屋の中のままなので、画面の境目にはなっていない。
参照の地図は、部屋が離れて並び、接している端を越えると隣の画面の反対側に出る。黒い隙間の向こうには部屋が無い。

## 判断

途中の部屋から出口の印を外す。右の端の開口に体が入ると、次の部屋の左の入口へ、速度を持ったまま移る。
井戸だけは上の端を抜け、次の部屋の入口に出る。
左の端を越えると、前の部屋の右の開口に戻る。案内は戻りを選ばない。人が戻ることはできる。
端の外は、その開口だけ通せる。ほかの外は壁のまま。
旗と CREST と登頂の停止は、道の最後の部屋だけ。その部屋の端からは次へ出ない。
画面をまたいだとき、ダッシュは入り直す。刻みは部屋ごとに戻す。案内の跳び方と物理の数は足さない。
参照の座標と輪郭は写さない。部屋は一つの格子には載せていない。開口の高さは、その部屋の入口と出口である。

## 比較した案

0033 の印を残す案は採らない。旗の字形を変えただけで、部屋の中の目標のままになる。
参照の階段状の部屋割りを写す案は採らない。
端の外を全部開ける案は採らない。歩きの途中で隣へ落ちる。
脇へそれて本線へ戻る部屋は足さない。案内は先の開口へ進む。

## 影響と検証

0033 の字形の出口は、この判断が置き換える。道の順は変えない。
最初の部屋の右の端は空き、その外は開口の高さだけ通る。同じ高さのほかの外は壁。
最初の部屋のかつて印があったマスは空で、旗の色ではない。旗は最後の部屋に一本。
無入力の案内は端を越えて次の部屋へ進み、最後の部屋だけ登頂する。
実機の感触は未計測。
