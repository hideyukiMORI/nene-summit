# ADR 0002 — Swift の記述とコミットの形を一つに固定する

Status: accepted
Date: 2026-11-01
Scope: 初期方針の技術判断。施主の確定要件ではない。

## 背景

施主は、Swift の実装規約を業界でも厳しい水準に固定し、整形・lint・記述を守り、
既存文書を Cursor が迷わない並びにし、兄弟リポジトリ群のコミット規約に揃えるよう依頼した。

NeNe Bolt `072d08af76a0f2045612c2e25b248df9b9496188` と
NeNe Swarm `33034861b846cf74528e87902358fd4b2cc88d2b` は、
Swift 6 の部分集合、`.swift-format`、`.swiftlint.yml` の `only_rules`、GIT-001〜005 をすでに一つの形にしている。
そこにある `active` と実測は、そのリポジトリで道具を動かした結果である。

## 判断

記述の正本を [CODING_RULES](../CODING_RULES.md) に置き、規則 ID は兄弟と同じ SWF-001〜018 に揃える。
Summit の旧要約が使っていた別の番号付けは廃止する。
整形の鍵は `.swift-format`、lint の名指しと閾値は `.swiftlint.yml`。数値を文書へ複製しない。
どちらのファイルも、P0 で版を実測し正例・反例とともに `make check` へ接続するまで実行しない。中身は緩めない。

コミットの形は兄弟の GIT-001〜005 に揃える。
メッセージ検証器は Summit で書き、フックと `make check` が同じものを呼ぶ。
親の無い初期化コミットだけ `(#N)` を欠いてよい。これは既存の初期化コミットを正当化する例外であり、新しいコミットには使わない。
兄弟の ruleset が守っている GIT-004 は、このリポジトリでは手順のまま残す。

文書のファイルは移動しない。作業別の索引は [docs/README](../README.md) の一つにする。
Cursor ルールは入口だけにし、規範の本文を複製しない。

## 比較した案

Bolt の完成済みゲートと `active` の表を写す案は採らない。未実行の検査を成功にするため。
SwiftLint の既定規則を一括で有効にする案は採らない。矛盾する規則を同時に入れ、正本が道具の機嫌になるため。
文書をサブディレクトリへ分割する案は採らない。既存のリンクと必須ファイル一覧が二重管理になるため。
初期化コミットへ遡って `(#N)` を付け直す案は採らない。歴史の改変であり、例外として検証器が識別できるため。

## 影響

判断の時点では Swift ソースは無く、SWF は planned、機械が守っていたのは GIT-003 だけだった。
その後の版の固定は [ADR 0003](0003-measured-toolchain.md)。どの SWF が active かは [QUALITY_GATES](../QUALITY_GATES.md)。
