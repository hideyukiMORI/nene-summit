# ADR 0016 — 画面は固定の色面にし、英語の四人で話す

Status: accepted
Date: 2026-11-01
Issue: #27
Scope: 設計案。施主は、画面と HUD を Swarm に倣うこと、英語にすること、四人で性格を変えること、色の面を基本にすることを求めた。色の番号と文面は施主の指定ではない。

## 背景

部屋ごとに画面の幅と高さが変わると、前の絵が残る。
山を `#` や `^` や `A` で描くと、文字が地形になる。
ボヤキは一人で、日本語だった。

Swarm の狭い画面は、上に題、左に固定の窓、右に状態、下にキー。盤面の正体は背景色で、文字は HUD に残す。
公開の解説では、例にした登山は描画の大きさを固定している。部屋の多くはその一画面ぶん。それより広い部屋は、窓を広げずにカメラが部屋の中を追う。部屋の形は写さない。

## 判断

毎フレーム、Swarm の狭い画面と同じ配置の格子を塗る。数は `Stage` に置く。この文書へ写さない。
山のマスは背景色の面。人が立つマス、床、棘、旗、頂も色で分ける。字形は置かない。
文字は、題、右の状態、ボヤキ、下のキーだけ。得点と残機は置かない。配色の切替は置かない。色の濃さと右の欄の段は [ADR 0023](0023-color-and-hud.md)。画面の枠と拾う光の数は [ADR 0024](0024-depth-and-gleam.md)。
部屋が窓より広ければ、体が窓の中央に来るよう原点を部屋の中に収める。窓は変えない。部屋が窓より小さければ、全体を見せて余りは空の色。
声は四人。英語。部屋を開くたびに次の人。棘、登頂、部屋を開いたときは割り込む。それ以外は間を置く。
文は回数で選ぶ。乱数は使わない。言葉は Engine。色は Render。物理は `SummitState.advance` のまま。
各行はカーソル位置で書く。行末に改行を置かない。幅いっぱいの改行は窓を送る。
同じ色が続くマスは、色を一度だけ出す。一フレームのバイトは、途中で捨てず末尾まで書く。

## 比較した案

部屋の大きさに合わせて画面を伸ばす案は採らない。前の絵が残る。
地形に文字や記号を置く案は採らない。施主は色の面を基本にするとした。
日本語の一人に戻す案は採らない。施主は英語の四人を求めた。
参照した登山の部屋をマスに写す案は採らない。
画面全体を毎フレーム消してから描く案は採らない。格子が毎回同じ大きさなら、行の残りを消すだけで足りる。
マスごとに色を出し直す案は採らない。一フレームが一度の書き込みより長くなり、床と人が画面に届かない。

## 影響と検証

[ADR 0015](0015-mutter-strip.md) の「帯は山の下」「声は一人」「日本語」は、本決定が置き換える。行末を消すことは残る。
Swift Testing が、どの部屋でも枠が同じであること、山に `#` と `^` が無いこと、
遠い棘が窓の外であること、四人の英語が順に出ること、登頂で題が替わることを見る。
無入力の登頂は残る。
平滑なカメラ、部屋をまたぐ補間、配色の切替、復元、リサイズは残る。
TERM-001 は planned のまま。実機の色とセリフの感じは未計測。
