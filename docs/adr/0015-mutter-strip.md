# ADR 0015 — 画面の下にボヤキを一行置き、枠の外は消す

Status: accepted
Date: 2026-11-01
Issue: #25
Scope: 設計案。施主の確定要件ではない。声の名前と文は施主の指定ではない。

帯を山の下に置くこと、声を一人にすること、日本語で話すことは [ADR 0016](0016-color-screen.md) が置き換える。行末と枠の下を消すことは残る。

## 背景

部屋の幅と高さが違う。前の画面は、新しい枠の外に残る。
画面の下は題、ダッシュ、キーだけで、誰も喋らない。
施主は、Bolt と Swarm のように HUD と描写を決め、ボヤキとジョークを入れてほしいと求めた。

読んだ形は、兄弟のいまの作業木にある。コードも台詞も人数も写していない。
Bolt は面の窓の下に 2 行の帯、その下に COMMS、下端にキー。
Swarm は左に盤面、右にパネル、80 桁では COMMS をパネルの中の 1 行にする。
どちらもセルを端末の 2 桁に広げ、得点と残機と複数の声を持つ。

## 判断

山を先に描き、その下に帯を置く。帯は題、ダッシュの印、ボヤキの一行、キーの一行。
右のパネルは置かない。部屋の幅が帯より広いことがあり、山を削らない。
セルは端末の 1 桁のまま。2 桁に広げると、広い部屋が 80 桁に入らない。
得点、残機、コイン、配色の切替、シードは置かない。

ボヤキは一人。きっかけは、部屋を開いたとき、跳んだとき、ダッシュ、棘、登頂。
棘と登頂は、直前に喋っていても言う。それ以外は間を置く。
文はきっかけの回数で選ぶ。乱数は使わない。同じ入力列は同じ文になる。
言葉を選ぶのは Engine。Render はその文字列を塗る。物理は `SummitState.advance` のまま。
はみ出した文は一行で切る。数はコードに置く。この文書へ写さない。

Terminal は毎フレーム、行の残りと枠の下を消す。画面全体を消してから描き直すことはしない。
ちらつく。リサイズの検査にはしない。

## 比較した案

兄弟の右パネルと 2 桁セルを採る案は採らない。部屋が枠に入らない。
得点と残機を足す案は採らない。登山の帯に要らない。
声を四人にする案は採らない。人数は兄弟の確定仕様ではない。
毎 tick 喋る案は採らない。読めない。
乱数で文を選ぶ案は採らない。同じ遊びが同じ画面にならない。
画面全体を毎フレーム消す案は採らない。残像が消える代わりにちらつく。

## 影響と検証

[ADR 0007](0007-shorter-jump.md) の帯は、ボヤキの一行が増える。題、ダッシュ、キーは残る。
Swift Testing が、狭い枠の文字列が行末と枠の下を消すこと、
部屋を開いた一言、間を置くジャンプ、棘と登頂が割り込むこと、帯にその文が出ることを見る。
無入力の登頂は残る。
配色、もう一人の声、先読み、復元、リサイズ、配布は残る。
TERM-001 は planned のまま。実機でゴミが消えたことと、ボヤキの感じは未計測。
