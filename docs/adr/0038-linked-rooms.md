# ADR 0038 — 一つの欄と、反対側からの入り

Status: accepted
Date: 2026-11-03
Issue: #79
Scope: 右の欄を一つの枠に戻し、出た側の反対から次の画面へ入る。一つの画面に障害を続ける。

## 背景

0037 の画面を施主が見た。右の欄の方向は良くなっている、と言った。
情報ごとに枠が分かれていることと、いまの画面の番号は要らない、と言った。
中身は、状態、拾ったもの、声がよい、と言った。
右へ出た次の画面で、右から出ている、と言った。
一つの障害を抜けると、あとは走るだけ、とも言った。
参照の序盤の走行を、数秒ごとに見た。一つの画面で、跳んで、着地して、次の隙間へ進んでいる。

## 判断

右の欄は一つの枠にする。中は状態、拾ったもの、声。区切りは枠の中の線。
画面の番号と、道順の一覧は出さない。得点、残機、配色の切替は足さない。
題と、反転したキーは残す。モードはオートと人が遊ぶのまま。
声は直近の数行を重ねる。古い行は暗く、新しい行は明るくする。
右へ出たら次は左の端から入る。左へ出たら右から、上へ出たら下から、下へ出たら上から入る。
入った端は、その部屋の出口にしない。
一つの画面には、跳ぶ、着地する、次の隙間、のように動作が続く。
最初の部屋は上へ抜ける縦穴で、途中の一方に棘がある。
続く部屋は、壁を蹴ったあとの棘、棘のあとの下の穴、落ちてから棘、壁を蹴ったあとの棘、つかまる昇り、ダッシュのあとの短い隙間。
案内の跳び方は部屋ごとに書かない。空中の二度目は 0037 の一度のまま。三度目は足さない。
参照のタイルと名前は写さない。

## 比較した案

情報ごとに枠を分ける案は採らない。施主が、一つの枠がよい、と言った。
画面の番号を残す案は採らない。施主が要らない、と言った。
出た側と同じ側から現れる案は採らない。右へ出た次が右から出る、と言った。
一つの障害のあとを廊下にする案は採らない。

## 影響と検証

0037 の「右を三つに分ける」と「道順を出す」と「一つの障害のあと走る」はこの判断が置き換える。
0037 の空中の一度、壁キック、つかまる床、案内が戻らないことは残る。
実機の感触は未計測。施主はこの画面をまだ見ていない。
