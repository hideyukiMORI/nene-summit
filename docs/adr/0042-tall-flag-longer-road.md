# ADR 0042 — 旗は縦に立て、空は動き、段を足す

Status: accepted
Date: 2026-11-03
Issue: #87
Scope: 旗は横線で囲わず、縦に 3 マス立てて色を強くする。雲は刻みでもずれ、星は白く光る。道に三段足す。

## 背景

0041 の画面を施主が見た。だいぶ良くなっている、と言った。
旗は `----` で囲わず、縦線を 2〜3 本にして高さを出し、色は派手にしてほしい、と言った。
足りない仕掛けを足し、パララックスと星のきらめきと雲の動きを入れてほしい、と言った。
段が短いので、もっと増やしてほしい、と言った。

## 判断

旗は一本のまま。布は列の一番上、その下は縦線を二本ずつ、合わせて 3 マス。
0027 の横の唇は、この旗だけ置き換える。当たりは頂上のまま。
旗の色は `Painter` の強い赤。チェックポイントの杭は変えない。
星の字を小さく明るい点にし、色は白。位置は今まで通り刻みで入れ替わる。
雲の形はカメラに加え、刻みでも横へずらす。刻み 0 の位置は変えない。
窓に収まる部屋のカメラは 0030 のまま動かさない。
道の十部屋のあとに、ばね、広い崩れる床と落ちる塊、もう一つの登りを足す。
最後の登りのあとが旗の部屋。旗は下から入る。
参照のタイルと名前は写していない。
新しい物理は足していない。速度は動かしていない。
空中の二度目は 0037 の一度のまま。

## 比較した案

旗を横に並べたまま色だけ変える案は採らない。施主が、横線で囲うな、と言った。
窓に収まる部屋のカメラを動かす案は採らない。0041 のまま。
三段を真上の穴だけにする案は採らない。案内が抜けられない形に戻る。

## 影響と検証

0041 の山のずれと、右上の旗の位置は残る。旗の字形と、道の長さをこの判断が足す。
実機の感触は未計測。施主はこの画面をまだ見ていない。
