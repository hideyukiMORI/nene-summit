# ADR 0044 — 一つの画面に仕掛けを重ねる

Status: accepted
Date: 2026-11-03
Issue: #91
Scope: 横穴と尖塔と煙突に、棘、消える足場、運ぶ床、落ちる塊を重ねる。最初の階段は細いまま。

## 背景

0043 の画面を施主が見た。よくはなっている、と言った。
全体が大味だ、とも言った。一画面でも迷路のように入り組み、仕掛けが複数ある感じにしてほしい、と言った。

## 判断

低い出口の部屋は、頭上を岩で閉じ、床に棘と消える足場を置く。ダッシュで越える部屋は棘を二列にする。出口の高さは足もとのまま。
着地の左端は岩にする。空きの一番左が果実だと、案内がそこから動かない。
果実と硬貨は離す。同じ tick に両方が体に触れると、果実だけが拾われる。
煙突は、消える足場と棘を短い縦穴に置く。折り返す階段にはしない。
尖塔は左から着くまま。穴と消える足場と落ちる塊を階段の途中に置く。
ばねの部屋は、棚を消える足場にする。地面の棘は置かない。
最初の階段と、旗の前の同じ階段は埋めない。頭上も塞がない。左の着地だけ、最初の段の上にする。
渡し舟は、運ぶ床と棘と消える足場と落ちる塊を同じ部屋に置く。乗らないと出られない、とはまだ言わない。
下へ出る部屋と、落ちた次の部屋は、高い床を足さない。
参照のタイルと名前は写していない。
新しい物理は足していない。速度は動かしていない。
空中の二度目は 0037 の一度のまま。
窓に収まる部屋のカメラは 0030 のまま動かさない。

## 比較した案

最初の階段を埋め、頭上を塞ぐ案は採らない。案内がその部屋から出なくなる。
低い出口の唇を上げる案は採らない。案内が真上へ跳び続ける。
煙突を折り返す案は採らない。案内は下へ戻る段を選ばない。
果実の隣に硬貨を置く案は採らない。ダッシュの一つの tick では果実だけが残る。

## 影響と検証

0043 の色と、尖塔の左着地は残る。部屋の数は十四のまま。
最初の階段は細いまま。横穴と煙突と尖塔とばねの棚に、仕掛けを重ねた。
渡し舟は、跳べば床に乗らずに越せるかもしれない。窓に収まる部屋のカメラは動かない。
実機の感触は未計測。施主はこの画面を見て、だいぶ良くなってると思う、と言った。遊びの記録はない。
