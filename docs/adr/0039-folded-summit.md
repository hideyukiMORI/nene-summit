# ADR 0039 — 道を折り、旗は下から登る

Status: accepted
Date: 2026-11-03
Issue: #81
Scope: 遊び始めの道を上、左、下、右へ折る。一つの画面に複数の障害を置く。旗は下から登った先にする。

## 背景

0038 の欄と画面の入りを施主が見た。欄と入りは良くなっている、と言った。
道は右へ抜け続ける。一つの画面の障害を越えると、あとは右へ走る、とも言った。
消える足場、落ちる塊、壁キック、運ぶ床は、すでに `advance` の中にある。
遊び始めの道には、ほとんど出ていなかった。
旗の部屋は横から入るので、山頂まで登った感じがしない、と言った。

## 判断

道は十部屋。出る向きは、上、左、下、右、右、上、右、右、右、上。
右だけが続く並びにはしない。終わりの三部屋は右へ出てから、上の縦穴、その上の旗へ入る。
一つの画面には、壁と消える足場、棘と下の穴、落ちる塊と消える足場、運ぶ床と棘、ダッシュと短い隙間、のように複数を置く。
新しい物理は足さない。案内の跳び方は部屋ごとに書かない。
空中の二度目は 0037 の一度のまま。三度目は足さない。
旗の部屋は、前の部屋の上から入る。旗は縦穴の上にある。横から歩いて旗が見える形にはしない。
旗の床は消える足場で、その下は空いている。入りの空きは、消える足場のマスを飛ばす。足場の中には立たせない。
参照のタイルと名前は写さない。

## 比較した案

右へ抜け続ける十部屋にする案は採らない。施主が、上にも左にも下にも進みたい、と言った。
旗を横の廊下の突き当たりに置く案は採らない。登った感じがしない、と言った。
落ちる塊と運ぶ床を、遊び始めの外に残す案は採らない。道の上で使う。

## 影響と検証

0038 の「右へ抜けて次の隙間」はこの判断が置き換える。
0038 の一つの枠、出た側の反対から入ることは残る。
0037 の空中の一度、案内が戻らないことは残る。
実機の感触は未計測。施主はこの画面をまだ見ていない。
