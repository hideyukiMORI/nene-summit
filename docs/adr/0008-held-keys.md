# ADR 0008 — 押しっぱなしと同時押しを端末の方式で受ける

Status: accepted
Date: 2026-11-01
Issue: #11
Scope: 設計案。施主の確定要件ではない。窓の長さは施主の実測ではない。

## 背景

キーを離したあとも数 tick 走り、同時に押した移動とジャンプが一つの入力にならない。
合成ルートが、文字のくり返しを固定 tick の残りで代用していた。
施主は、Bolt の入力と端末の公式の方式を見るよう求めた。

## 判断

端末の読みは Terminal の一つの経路。実行ファイルは押されているキーを `PlayChord` に渡し、`Input` を一つ作る。
状態は `SummitState.advance` だけが進める。

開始時に二つの頼みを出す。
Kitty keyboard protocol の `CSI = 11 u` は、escape の区別、出来事の種類、文字キーも escape で届けること（公式の旗 1、2、8）を一度に置く。
Windows Terminal の win32-input-mode は `CSI ? 9001 h`。列は `ESC [ Vk ; Sc ; Uc ; Kd ; Cs ; Rc _`。
終了時は `CSI < u`、`CSI = 0 u`、`CSI ? 9001 l` で戻す。
読めない端末は、これまでどおり文字と `ESC [ A` から `D`、`ESC O A` から `D` を送る。

押す・離すが届く列は、離すまで押している。届かない文字は、くり返しが続くあいだ押している。
窓の長さは `HeldPresses` だけが持つ。この文書へ写さない。Bolt が同じ端末の制約として置いた窓を、ここで測り直してはいない。
1 tick のあいだに押して離した打鍵は、次の取り出しまで残す。
列が読みの途中で切れたら、終端が届くまで残す。

同じ tick の複数キーは一つの `Input`。左と右、上と下は、両方押しているあいだ打ち消す。
ジャンプは押し始めの 1 tick だけ。`w` と上矢印もジャンプの押し始めにする。押しっぱなしは再ジャンプしない。
離した tick で、まだ上がっていてダッシュ中でない速度だけを `MotionPolicy` で短くする。数は書かない。
ダッシュも押し始めの 1 tick だけ。同じ tick ではジャンプがダッシュに勝つ、は [ADR 0005](0005-playable-climb.md) のまま。

時計は実行ファイルがミリ秒を渡す。Terminal は時計を読まない。Core に秒を置かない。

## 比較した案

固定 tick の残りで押し続ける案は採らない。端末が離したと言えるのに無視する。
kitty だけ、または win32 だけにする案は採らない。公式の keyboard protocol と、Bolt が使っている Windows Terminal の方式を両方読む。
ジャンプを押しているあいだ毎回跳ぶ案は採らない。押し始めだけにする。
後から押した左右を勝たせる案は採らない。Bolt の操作と同じく、両方で打ち消す。

## 影響と検証

[ADR 0005](0005-playable-climb.md) の「キーを押し続けたとみなす固定の長さ」は、この判断が置き換える。
`advance` が唯一の経路であることは残る。

Swift Testing が、1 回の読みの右とジャンプ、左右の打ち消し、win32 の押す・離す、kitty の押す・くり返し・離す、
文字のくり返し窓、短い打鍵の取りこぼしなし、ジャンプの押しっぱなしが再ジャンプしないこと、
離した tick の上昇が短くなること、ダッシュの押しっぱなしが一度しか発火しないことを見る。
PTY は起動のあと `q` だけ。復元とリサイズは未検査なので、TERM-001 は planned のまま。
実機の Windows Terminal で両方の列が同時に届くかは未計測。届いた列は順に反映する。
複数の部屋、先読み、テーマ、配布は残る。
