# ADR 0035 — 壁と消える床を道の上に置く

Status: accepted
Date: 2026-11-03
Issue: #73
Scope: 井戸は壁を蹴らないと右の端へ出られない。落ちる塊のあとに、崩れる橋を置く。

## 背景

0034 は端の開口で隣の画面へ移る。井戸だけは上の端を抜けていた。
地面を歩いても次へ出られる部屋があり、壁に沿う必要がなかった。
崩れる床は最後の旗の部屋に一つあるだけで、道の途中では消える足場も落ちる橋も要らなかった。
窓より狭い部屋は、部屋の右端が画面の途中にあり、そこに重なると隣へ出ていた。

## 判断

井戸の上抜けをやめる。地面の先は壁で、左の壁に沿って一度蹴り、棚の上へ出る。
棚の手前は周期で消える足場で、その先の右端が次の画面である。
落ちる塊の部屋のあと、二つの岸と、そのあいだの崩れる橋を置く。橋の下は空き、底は棘。
旗の部屋の前に、速さや向きの違う動く床と、果実と硬貨のある部屋を足す。
部屋が窓より狭いときは、右端が窓の端に揃うまで床と空を足す。旗の部屋は足さない。
隣へ出るのは、体が部屋の外へ出たときだけ。最後の列に重なっただけでは出ない。
案内は、今歩いて落ちるときだけ、少し待ってから右へ歩く。壁に触れた最初の跳びは、壁の外へ蹴る先を見る。
左へ戻ることは人ができる。案内は戻りを選ばない。
踏んだ記録では床を消さない。案内の跳び方を部屋ごとに書き分けない。物理の数は足さない。

## 比較した案

井戸の上抜けを残す案は採らない。地面を歩くだけで次の画面へ出る。
窓より狭い部屋を、画面の途中で隣へ出す案は採らない。0034 の端が、窓の端にならない。
踏んだマスだけ消える床は採らない。0028 と同じく、周期だけにする。
参照の部屋割りと名前は写さない。

## 影響と検証

0034 の「井戸は上の端」はこの判断が置き換える。端を越えると隣へ入ることと、旗が最後だけであることは残る。
0020 の井戸は、上へ抜ける穴から、右の端へ出る棚に変わる。
案内は壁の相を経て次の部屋へ進み、崩れる橋の上を通り、果実か硬貨を持って旗の部屋へ着く。
実機の感触は未計測。
